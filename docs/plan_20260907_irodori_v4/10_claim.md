# Irodori v4.1 移行の目的

作成日: 2026-09-07。対象: fm-live-radio、基準コミット db03bec8。

## 目的

現行の Irodori-TTS-500M-v3 によるラジオ原稿読み上げを、Go/ONNX のローカル実行形態を維持して v4.1 世代へ更新する。日本語の読み、既存ナレーターの声、生成待ち時間を実測で比較し、切替後も元の v3 に戻せるようにする。

## 確認済みの方針

- Full 形式、E2E 検証計画、作業ログあり。
- ユーザー選択: Go/ONNX を維持し、v4.1 を第一候補とする。
- 今回の成果物は調査・動作確認・移行計画。製品の推論実装や既定モデルは変更しない。

## 背景と不確実性

公式 v4.1 は v4 の duration predictor を更新したモデル。現行の 500M-v3 base と、公式比較表にある 600M-v3-VoiceDesign は異なるため、公開スコアだけでは本アプリでの改善を断定できない。

公式 Python 実装で v4/v4.1 の生成に成功したが、現行 Go tokenizer は公式と不一致、現行 exporter は v4.1 の実モデルで非互換だった。モデルの差し替えだけでは移行できない。ONNX 対応の実現性・品質・CPU/CUDA 性能の検証を、既定切替より前に置く。

調査の根拠は [調査記録](../cheatsheet/irodori-v4-migration.md)、全体説明は [レビュー資料](60_review_packet.md) を参照する。
