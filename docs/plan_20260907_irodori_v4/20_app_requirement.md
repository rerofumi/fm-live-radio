# アプリ要件

## 利用者と結果

ラジオ利用者は、現在の narrator WAV と RSS 由来の日本語原稿で、BGM の間にニュース音声を再生する。移行後も Python サーバーを手動で起動する必要はない。

## 初回移行の範囲

- Windows x64、Go + ONNX Runtime、既存の auto/cuda/cpu 設定を維持する。
- v4.1 の ONNX 変換、tokenizer、参照音声条件、発話長予測、生成ループを対応させる。
- 現在の単一参照 WAV と、参照なしの動作を検証する。音声出力は 48 kHz / mono / PCM16。
- 現在の文分割・文間 300 ms・失敗文 3 秒無音という外部動作を原則維持する。ただしモデル非互換は文ごとの失敗に入る前に明示エラーとする。
- 保存済み設定と v3 資産を残し、手動で v3 に戻せる。
- 現行の caption UI はない。初回移行は caption を空として利用するが、モデル内部では caption と speaker を独立した条件として扱う。

## 初回に含めないもの

複数参照 WAV の UI、caption 編集 UI、120 秒参照の品質最適化、LoRA、speaker inversion、量子化、WebGPU、常駐 Python サーバー化、BGM モデル更新は別途検討する。これらを v4.1 採用理由の検証済み機能として扱わない。

## 切替の条件

2026-09-08の[利用者採用判断](evidence/user-acceptance-v41.md)によりv4.1を採用する。Go/ONNXの正確性・生成期限・共存/取消安全と利用者が許容した品質を基に、新規設定の既定値をv4.1へ更新する。v3同等の性能/消費資源は採用条件にしない。既存ユーザーのmodelDirを無断で書き換えない。未観測の実Wails音声操作は計画の残確認として保持し、モデル採用とは分離する。
