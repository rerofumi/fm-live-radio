# ローカル音声合成の基本

ローカル音声合成は、原稿と声の手がかりから音声を作り、ラジオの話し声として届ける処理である。利用者は原稿・ナレーター・音量を選び、生成器は音声を作り、再生器はBGMとの順序や間を調整する。

## 用語と区別

- 参照音声: 話者の声の特徴を伝える入力。生成する文章の長さとは別のもの。
- caption: 話し方や声の特徴の文章指示。参照音声と矛盾すると結果が不安定になることがある。
- tokenizer / text encoder: 文章を数値へ変え、その文脈を解釈する。モデルと同じ変換規則が必要。
- codec / latent: 波形とモデル内部の音声表現を相互変換する。サンプル数とlatent frame数は異なる。
- duration predictor: 必要な発話長を予測する。長すぎると余計な反復、短すぎると読み切れない場合がある。
- steps / CFG / seed: 生成の計算回数・条件の効かせ方・乱数の指定。同じseed値でも別実装では同じ乱数列にならない。
- ONNX export: 学習用実装を配布用の計算graphへ変換する。ファイルが作れたことと、元と同じ計算をすることは別々に確認する。

## 成立条件

音声が非無音であるだけでは十分でない。文章を読み切り、声質が用途に適し、次の再生までに生成が終わり、BGMと共存する必要がある。速度はロード時間、合成時間、生成音声の秒数を分ける。品質は読み・自然さ・声の一貫性を人が確かめる。

モデル、tokenizer、codec、条件tensorの組を対応させること、取消時に実行中の資源を壊さないこと、音声形式を再生器と一致させることは、要件とE2Eへ引き継ぐ不変条件である。
